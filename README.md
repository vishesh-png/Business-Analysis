# Allo — Business Analysis

Business Analysis tracker: one metric at a time (Revenue, Gross / Net utilization,
No show by gross, Bookings, B2D, Prescribe AOV, Conversion, Purchase AOV, RPC) in a
metro / ROI-cluster → doctor (clinic) × period grid, with channel, window (month /
week / day, multi-select weekday), diagnosis and city filters.

Access is password-protected. Built from the local `allo-bi/business-analysis-tracker/`
pipeline (`refresh.sh` = `fetch_data.py` + `build_deploy.sh`); this repo only ever
holds the encrypted page.
